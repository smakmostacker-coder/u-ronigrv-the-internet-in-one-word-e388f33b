One word for the whole internet: **feral**.

The internet isn't a product, a place, or a mood — it's wild, untamed, and unmoderated. Nothing about it was ever domesticated. It bites, it multiplies, it cannot be house-trained.

## How it works

`main.ts` is a deterministic program (standard library only, no network, no randomness) that writes the single word to `/output/entry.txt`. That file is the entry — the word and nothing else.
